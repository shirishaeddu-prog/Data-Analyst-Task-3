 Task 3: SQL for Data Analysis

Objective
The objective of this task is to use SQL queries to extract and analyze data from an e-commerce database.

Tools Used
- Python
- SQLite
- Pydroid 3

Dataset
A simple e-commerce sales dataset containing:
- Customer name
- Product
- Category
- Price


SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- AVG()
- SUM()
- GROUP BY
- Subquery

Description
In this task, an SQLite database is created using Python. 
Sample e-commerce sales data is inserted into the database and different SQL queries are used to analyze the data.

The program finds:
1. Products with price above ₹5000
2. Products sorted by price
3. Average product price
4. Total sales by category
5. Products above the average price

 How to Run
1. Open Pydroid 3.
2. Create a new Python file.
3. Paste the Python code.
4. Run the program.
5. Take a screenshot of the output.

 Output
The program displays the results of different SQL queries in the Pydroid 3 console.

Conclusion
This task helped me understand how SQL queries can be used with SQLite and Python for basic data analysis.# Data-Analyst-Task-3
